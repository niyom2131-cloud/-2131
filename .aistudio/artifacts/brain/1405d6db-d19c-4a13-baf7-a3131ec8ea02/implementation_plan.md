# ระบบลงทะเบียนและเช็คชื่อร่วมงานเลี้ยงรุ่น นนส.เหล่าทหารขนส่ง (NNS. Transport Reunion App)

เว็บแอปพลิเคชันลงทะเบียนเข้าร่วมงานเลี้ยงคืนสู่เหย้า นนส.เหล่าทหารขนส่ง (รุ่น 21/31) แบบครบวงจร รองรับการค้นหารายชื่อเพื่อนร่วมรุ่นอัตโนมัติ การอัปโหลดสลิปโอนเงิน การออกบัตร QR Code สำหรับเข้างาน และระบบแดชบอร์ดสำหรับคณะกรรมการผู้ดูแลระบบในการตรวจอนุมัติสลิป สแกน QR Code เช็คชื่อหน้างานแบบเรียลไทม์ และส่งออกข้อมูลเป็นไฟล์ Excel

---

### User Review & Critical Decisions

> [!IMPORTANT]
> สรุปข้อตกลงและแนวทางการพัฒนาที่ยืนยันจากผู้ใช้งานใน Phase 1:
> - **ประเภทระบบ**: ระบบลงทะเบียนและเช็คชื่อร่วมงานเลี้ยงรุ่น นนส.เหล่าทหารขนส่ง ตามโครงสร้างไฟล์ต้นแบบ
> - **ฟังก์ชันหลัก**: หน้าลงทะเบียนพร้อมค้นหารายชื่อ 79 นาย, ระบบแนบและตรวจสอบสลิปการชำระเงิน, ออกบัตร QR Code เฉพาะผู้ได้รับการอนุมัติ, ระบบสแกน QR Code เช็คชื่อหน้างาน
> - **การจัดเก็บข้อมูล**: จัดเก็บและซิงค์ข้อมูลผ่าน Local Database ในเบราว์เซอร์ พร้อมระบบ Export เป็นไฟล์ Excel/CSV และ Import สำรองข้อมูล เพื่อความสะดวกและไม่พึ่งพาเซิร์ฟเวอร์ภายนอกที่ซับซ้อน

- **รหัสผ่านเข้าสู่ระบบผู้ดูแล (Admin)**: กำหนดรหัสผ่านเริ่มต้นที่จำง่ายและเปลี่ยนได้ เช่น `admin2569` หรือ `nnskhs2131` พร้อมปุ่ม Quick Login เพื่อให้กรรมการใช้งานหน้างานได้ทันที
- **รายชื่อศิษย์เก่าตั้งต้น**: นำเข้ารายชื่อ นนส.เหล่าทหารขนส่ง 21/31 ทั้งหมด 79 นาย (รวมชื่อคุณนิยม สมาคม และเพื่อนร่วมรุ่น) และเปิดให้พิมพ์ชื่อกรณีเพิ่มเติมได้อิสระ

### 1. Overview & Core Concept

- **วัตถุประสงค์**: เพื่ออำนวยความสะดวกให้ศิษย์เก่า นนส.เหล่าทหารขนส่ง ลงทะเบียนเข้าร่วมงานเลี้ยงรุ่น แจ้งจำนวนผู้ติดตาม ขนาดเสื้อ ประเภทอาหาร แนบหลักฐานการโอนเงิน และรับบัตร QR Code ประจำตัว ขณะเดียวกันคณะกรรมการจัดงานสามารถตรวจสลิป อนุมัติยอด สแกนเช็คชื่อ และสรุปยอดผู้เข้าร่วมงานได้ทันที
- **กลุ่มผู้ใช้งาน**:
  1. *ศิษย์เก่า/ผู้เข้าร่วมงาน*: ใช้งานผ่านสมาร์ตโฟนเพื่อลงทะเบียน ตรวจสอบสถานะ และแสดง QR Code เข้างาน
  2. *คณะกรรมการ/ผู้ดูแลระบบ*: ใช้งานผ่านแท็บเล็ตหรือคอมพิวเตอร์เพื่อตรวจสลิป, สแกน QR Code หน้างาน, และ Export รายงาน
- **คุณค่าหลัก**: รวดเร็ว ไม่ซับซ้อน ไม่ต้องลงแอปพลิเคชันเพิ่มเติม ตรวจสอบสลิปได้แบบ Inline Lightbox และสแกน QR Code เช็คชื่อหน้างานได้ไวในเสี้ยววินาที

### 2. User Experience & Visual Design

#### A. Key User Flows
1. **Flow ผู้เข้าร่วมงาน (Public Registration)**:
   - **หน้าแรก (Home)**: แสดงชื่องาน กำหนดการ สถานที่จัดงาน พร้อมปุ่ม "ลงทะเบียนร่วมงาน" และ "ตรวจสอบสถานะ / รับ QR Code"
   - **แบบฟอร์มลงทะเบียน (Register)**:
     - *ขั้นตอนที่ 1*: เลือก/ค้นหาชื่อ นนส. จากรายชื่อแนะนำ 79 นาย (หรือพิมพ์เอง), เบอร์โทร, ไลน์ไอดี, จังหวัดปัจจุบัน
     - *ขั้นตอนที่ 2*: จำนวนผู้ติดตาม, ขนาดเสื้อ (S, M, L, XL, XXL, 3XL), ประเภทอาหาร (ทั่วไป, อิสลาม, มังสวิรัติ), ข้อความถึงเพื่อน
     - *ขั้นตอนที่ 3*: บัญชีธนาคารสำหรับโอนเงิน, ช่องอัปโหลดรูปภาพสลิปโอนเงิน (แปลงเป็น Base64 Data URL ดูตัวอย่างภาพได้ทันที), วันที่และเวลาโอน
   - **หน้าสำเร็จ (Thank You & Confirmation)**: แสดงรหัสอ้างอิงและแจ้งเตือนรอแอดมินตรวจสอบสลิป
   - **หน้าตรวจสอบสถานะ (Check Status)**: ค้นหาด้วยเบอร์โทรศัพท์หรือชื่อ แสดงสถานะ (รอตรวจสอบ / อนุมัติแล้ว / ปฏิเสธ)
   - **หน้าบัตร QR Code (My QR Code)**: เมื่อได้รับการอนุมัติ จะสร้างบัตรประจำตัวดิจิทัลพร้อม QR Code ขนาดใหญ่สำหรับสแกนเข้างาน พร้อมปุ่มบันทึกรูปบัตรเข้าเครื่อง

2. **Flow ผู้ดูแลระบบ (Admin Workspace)**:
   - **Admin Login**: ป้อนรหัสผ่านผู้ดูแลเพื่อเข้าสู่ระบบ
   - **Dashboard ภาพรวม**: สรุปยอดลงทะเบียนทั้งหมด, จำนวนผู้เข้าร่วมสุทธิ (รวมผู้ติดตาม), ยอดเงินที่อนุมัติแล้ว, จำนวนที่เช็คชื่อเข้างานแล้ว
   - **ระบบคิวตรวจสลิป (Pending Queue & Lightbox)**: คลิกดูรูปสลิปขยายใหญ่ กด "อนุมัติ" หรือ "ปฏิเสธ (พร้อมระบุเหตุผล)" ได้ในคลิกเดียว
   - **ทะเบียนรายชื่อ (Participants Directory)**: ตารางรายชื่อ ค้นหา กรองสถานะ แก้ไขข้อมูล ลบข้อมูล และเพิ่มผู้ลงทะเบียนแทน
   - **ระบบสแกน QR Code หน้างาน (QR Scanner)**: ใช้กล้องสมาร์ตโฟน/โน้ตบุ๊กสแกนบัตร QR Code ของเพื่อน เสียงติ๊ดแจ้งเตือน เช็คชื่อสำเร็จ พร้อมแสดงจำนวนผู้ติดตามทันที
   - **ส่งออกรายงาน Excel (Export to Excel/CSV)**: ดาวน์โหลดไฟล์ Excel สรุปรายชื่อผู้เข้าร่วมงาน ยอดเงิน ขนาดเสื้อ และสถิติการเช็คชื่อ

#### B. Visual Identity & Theme
- **Theme & Atmosphere**: สุภาพ มั่นคง ทรงเกียรติ ให้ความรู้สึกภาคภูมิใจในความเป็นทหารขนส่ง ผสมผสานโทนสีฟ้าคราม/น้ำเงินกรมท่าสุภาพ (Navy/Steel Blue) และทองเกียรติยศ (Warm Brass/Gold) พื้นหลังสี Pale Cool Gray สะอาดตา อ่านง่าย
- **Design Constitution Compliance**:
  - *Zero-Pill Discipline*: ข้อมูลวันที่และสถิติแสดงแบบตัวอักษรเรียบหรูพร้อมจุดแบ่ง typographic `·` ปราศจาก pill badges รกตา
  - *Top Bar Contract*: แถบนำทางแถวเดียว แบ่ง 3 โซนชัดเจน (ตราสัญลักษณ์ นนส.เหล่าทหารขนส่ง — เมนูนำทางเรียบง่าย — ปุ่มเข้าสู่ระบบผู้ดูแล)
  - *Tabular Numerals*: ตัวเลขสถิติ ยอดเงิน เวลา และเบอร์โทรใช้ `font-mono tabular-nums` เพื่อความตรงแถวและอ่านง่าย
  - *Mobile Sticky Cap*: ควบคุมความสูงปุ่มหรือแถบลอยบนมือถือไม่เกิน 15% ของหน้าจอ ใช้งานสะดวกด้วยมือเดียว

### 3. Key Product Decisions & Trade-Offs

- **การจัดเก็บข้อมูลแบบ Client-side Reactive Store (IndexedDB + LocalStorage)**:
  - *เหตุผล*: ปลอดภัย รวดเร็ว 100% ทำงานได้ทันทีบนเบราว์เซอร์ ไม่ต้องติดตั้งฐานข้อมูลภายนอกให้เกิดความยุ่งยากหรือล่มหน้างาน
  - *การสำรองข้อมูล*: เพิ่มปุ่ม "สำรองข้อมูล (Export JSON/Excel)" และ "กู้คืนข้อมูล (Import)" สำหรับแอดมิน เพื่อความมั่นใจในการใช้งานจริง
- **การจัดการภาพสลิปโอนเงิน (Image Processing)**:
  - บีบอัดรูปสลิปให้อยู่ในขนาดกะทัดรัดด้วย Canvas Client-side ก่อนบันทึกเป็น Base64 ทำให้ไม่เปลืองพื้นที่ความจุเบราว์เซอร์ และโหลดดูสลิปได้ทันทีโดยไม่มีปัญหาภาพไม่ขึ้น
- **ระบบสร้างและสแกน QR Code ในตัว (Built-in QR Engine)**:
  - ใช้ `qrcode` library สำหรับเรนเดอร์บัตร QR Code ความละเอียดสูง และใช้กล้องผ่าน WebRTC API (HTML5 Video Stream) สำหรับสแกนหน้างาน พร้อมโหมดพิมพ์ค้นหารหัส Token สำรองหากกล้องของผู้ใช้มีปัญหา

#### Data Entities
- **Participant Entity**:
  - `id`: string (UUID / Timestamp)
  - `fullName`: string (ชื่อ-นามสกุล)
  - `nickname`: string (ชื่อเล่น)
  - `classYear`: string (รุ่น 21/31 เหล่าทหารขนส่ง)
  - `phone`: string (เบอร์โทรศัพท์ สำหรับค้นหาสถานะ)
  - `lineId`: string (LINE ID)
  - `province`: string (จังหวัดที่พำนักปัจจุบัน)
  - `guestCount`: number (จำนวนผู้ติดตาม)
  - `totalCount`: number (รวมตัวเองและผู้ติดตาม)
  - `foodType`: "general" | "muslim" | "vegetarian"
  - `shirtSize`: "S" | "M" | "L" | "XL" | "XXL" | "3XL"
  - `message`: string (ความในใจถึงเพื่อนร่วมรุ่น)
  - `paymentAmount`: number (ยอดเงินที่โอน เช่น 1,000 บาท)
  - `paymentDate`: string (วัน-เวลาโอนเงิน)
  - `slipDataUrl`: string (รูปภาพสลิปแบบ Base64 สำหรับเปิดดูได้ทันที)
  - `status`: "pending" | "approved" | "rejected"
  - `adminNote`: string (หมายเหตุจากกรรมการ)
  - `qrToken`: string (รหัสตรวจสอบความถูกต้องของบัตร QR Code)
  - `checkedIn`: boolean (สถานะเข้างาน)
  - `checkedInAt`: string | null (เวลาที่สแกนเข้างาน)
  - `createdAt`: string

### Step-by-Step Implementation Sequence

1. **Setup Assets & Data**:
   - บันทึกชุดข้อมูลรายชื่อศิษย์เก่า นนส.เหล่าทหารขนส่ง 21/31 ทั้ง 79 นาย
   - ติดตั้ง Utility Library ที่จำเป็นสำหรับการสร้าง QR Code และสร้างไฟล์ Excel (`qrcode`, `xlsx`)
2. **Data & Storage Layer (`src/lib/storage.ts`)**:
   - สร้างคลังข้อมูลผู้ลงทะเบียน รองรับการบันทึก, อนุมัติ, สแกนเช็คชื่อ, และนำเข้าข้อมูลเริ่มต้น
3. **Public Pages**:
   - หน้าแรก `Home`: กำหนดการงานเลี้ยงรุ่น นนส.เหล่าทหารขนส่ง 2569, รายละเอียดสถานที่, ลิงก์ด่วน
   - หน้าลงทะเบียน `Register`: ฟอร์ม 3 สเต็ปค้นหาชื่อเพื่อนอัตโนมัติ, กรอกข้อมูลร่วมงาน, แนบสลิปพร้อมพรีวิว
   - หน้าขอบคุณ `ThankYou`: สรุปข้อมูลและลิงก์ตรวจสอบสถานะ
   - หน้าตรวจสอบสถานะ `CheckStatus`: ค้นหาด้วยเบอร์โทร
   - หน้าบัตร `MyQrCode`: แสดงบัตร QR Code พร้อมดาวน์โหลด
4. **Admin Pages**:
   - หน้าเข้าสู่ระบบ `AdminLogin`: ป้อนรหัสผ่านกรรมการ
   - หน้าแดชบอร์ด `AdminDashboard`: กราฟและสถิติ, คิวรอตรวจสลิปพร้อม Lightbox
   - หน้าจัดการรายชื่อ `AdminParticipants`: ค้นหา กรอง แก้ไข และลงทะเบียนแทน
   - หน้าสแกน QR Code `AdminQrScanner`: ระบบเปิดกล้องสแกนบัตรเช็คชื่อหน้างานทันที
   - ฟังก์ชันส่งออก Excel: ดาวน์โหลดไฟล์รายชื่อผู้เข้าร่วมงานครบทุกคอลัมน์
5. **Verification**:
   - ตรวจสอบการคอมไพล์ผ่าน `compile_applet` และทดสอบฟังก์ชันการทำงานทุกส่วนให้สมบูรณ์
